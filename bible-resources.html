🔐 Your privacy and backup

All prayer entries, notes, highlights, bookmarks and plan progress are stored on your device. This app has no account, ads or tracking. Export a backup before changing phones or clearing browser data.

📱 Install & offline

For a phone-like app, host these files on HTTPS (for example Netlify or GitHub Pages), open in Chrome, then use ⋮ → Add to Home screen → Install. The app shell will be available offline; download KJV once while online for offline Scripture.

Opening the HTML file directly works for the study guides, notes and plans, but some Chrome versions restrict offline installation or downloaded data from local files. Hosting the ZIP's files is recommended.
